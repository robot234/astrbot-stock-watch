# 选股方法盘点与可行性评估（2026-10-07）

本文只汇总已有研究的结论，没有新跑回测、没有改选股规则、没有改风险门槛。
“可行性评级”是依据现有证据的定性判断，**不是校准过的概率**；要得到可以当概率用的结论，只能靠预先登记标准的前瞻样本。
策略调整仍按 `STRATEGY_ITERATION_CHECKLIST.md` 逐项给证据、等用户确认。

## 0. 一句话结论

到今天为止，**没有任何一条规则在扣费后的样本外或前瞻数据上证明了正收益**。
几条规则在各自“研究期”显著，换一段时间就消失；同一股票池里随机挑股常常不比规则差。
唯一在样本内外方向都一致的线索，是“低换手、低波动、短期刚下跌”的横截面排序信号（因子 v1 rank IC 为正），但按“每天只买第 1 只、持有 3 天”的方式执行没有赚到钱。
正式名单为 0 的直接原因是四项风险证据门槛（S01/S02），不是选股条件太严。

## 1. 评级口径

| 评级 | 含义 |
|---|---|
| 高 | 样本外或前瞻已经显示扣费后正超额，并且稳健（目前没有） |
| 中 | 有稳定的样本外排序信号或合理的新假设，但还没转化成扣费收益，值得写新协议做前瞻 |
| 低 | 研究期有迹象，样本外消失；或只在很小样本里出现 |
| 极低 | 样本外明确为负，或输给同池随机 |
| 不可评估 | 还没有收益检验，或样本太小、账户不完整 |

## 3. 从这些失败里能确定的规律

1. **成本吃掉了短线优势。** 1 万元单只的往返成本约 0.2%—0.3%（最低 5 元佣金、卖出印花税、双边滑点）。D1—D5 的规则每笔要稳定超过这个数，目前没有一条做到。
2. **股票池本身偏弱，随机常常不输。** 成交额前 300、价格 2—80 元的池子在 2024—2026 的 D3 本身就为负；规则大多没能比同池随机好。
3. **强烈的阶段依赖。** 在 2024 年显著的规则（UPTREND、COOL8）到 2025—2026 明显变弱，说明在已看数据上选规则很容易过拟合。
4. **“避开过热”方向一致。** 近期涨幅大、远离均线、放量、特异波动大的股票之后跑输，这个方向在多个窗口一致。它更适合做排除过滤，而不是单独当选股收益来源。
5. **低换手 / 低波动排序在样本外仍有效。** rank IC 在 holdout 仍为正（t 3.2），但“每天只买 1 只、拿 3 天”把排序优势全浪费在噪声和成本上。
6. **数据完整性决定能不能下结论。** 多个研究因为公司行动、入场证据缺失，账户无法完整核对。要评价持有超过几天的策略，需要复权因子和分红现金流。
7. **正式名单为 0 与选股无关。** HERMES40 旁支已证明候选每天都有（约 32 只通过），正式名单为 0 是四项风险证据门槛造成的。

## 4. 可以考虑的其他方案

以下都是**新假设**，要按检查单先写“假设 / 赢的标准 / 放弃条件”，用户确认后才能计算；不得在已看过的数据上挑赢家。

| 方案 | 思路 | 为什么值得试 | 需要的数据 / 代价 | 初步评级 |
|---|---|---|---|---|
| A. 横截面因子组合（多只等权、周或月调仓） | 用因子 v1 的低换手 / 低波动 / 短反转合成，取前 10%（20—50 只）等权，每周或每月调仓，和全池等权、中证 1000/500 比 | 唯一在样本外仍有效的排序信号；分散持仓降低噪声；原执行方式年化换手约 109 倍，改成周 / 月调仓后换手和成本都会大幅下降 | 现有日线即可；需要复权和分红才能算完整账户；需要从未看过的时间段（如 2017—2020）或只用前瞻 | 中 |
| B. 低波动防御组合 + 市场状态降仓 | 在 A 的基础上，按插件已有的全市场宽度 / 中位涨跌判断风险偏弱时降仓 | 目标是降低回撤，而不是追高收益；插件已有市场状态计算 | 同 A；评价指标改成回撤和账户胜率 | 中 |
| C. 行业 / 风格 ETF 轮动（月度） | 在 83 个行业或宽基 / 行业 ETF 上做动量或反转轮动 | ETF 没有单只股票的 ST、停牌、退市问题，**绕开了当前卡住正式名单的四项风险门槛**；成本低、可成交性好 | 指数 / ETF 日线（AKShare 或 Tushare index_daily） | 中 |
| D. 宽基 ETF + 简单趋势过滤 | 例如中证 500/1000 ETF 加 200 日均线或宽度过滤 | 不是选股收益，而是稳健参与；适合“要稳”的目标 | 指数 / ETF 日线 | 中（作为风险可控的参与方式） |
| E. 公告事件：业绩预告超预期、回购 / 增持后的漂移 | 用点时公告做事件研究 | 事件驱动比纯技术更有经济含义；插件已有官方公告证据适配器 | 需要点时公告全量（巨潮），数据建设量大 | 中（数据门槛高） |
| F. “过热回避”做成过滤标签 | 把 COOL8 的过热指标作为任何候选 / 自选的风险标签，前瞻统计被标记股票是否更差 | 实现成本低，只做显示，不改正式门槛 | 现有数据 | 中（作为过滤） |
| G. LLM 用于风险 / 公告解读，而不是选股 | 让模型从公告里抽取 ST 风险、审计意见、诉讼等风险线索，进入风险证据链 | 正好对准当前真正的卡点（风险 unknown）；结果可以用结构化数据核对 | 需要和 S01 的验收口径对齐，模型输出必须可追溯 | 中（作为工具） |

## 5. 建议

1. **先让已冻结的前瞻继续跑，不改规则**：四项风险 20 日存档（S02，10-08 起）、COOL8 前瞻（约 2027-01 首次复盘）、超短 V1 前瞻（S07）。
2. **如果要开新一轮，优先方案 A（可以同时带上 B 的降仓规则）**：证据最强，按检查单先写第 1—3 项给用户确认；只用从未看过的数据或前瞻。
3. **如果目标是尽快有可执行的稳健名单，优先 C / D**：ETF 不受单只股票风险门槛限制，但它是“稳健参与”，不是“选出会涨的股票”。
4. **数据前置**：复权因子与分红（完整账户必需）、点时公告（事件研究必需）、指数 / ETF 历史（轮动必需）。
5. **不要做的事**：不在已看过的 2021—2026 数据上继续调参挽救失败规则；不把评分、涨幅或命中率说成上涨概率。
