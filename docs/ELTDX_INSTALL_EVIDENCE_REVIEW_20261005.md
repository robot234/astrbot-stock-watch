## 不得升级为已通过的部分

1. 服务器交易日期为2026-09-30；10-05取得的是保留数据，不能变成10-05新行情或10-08独立参考。
2. `daily_price_limits`用历史日线、权息资料和库内规则计算。即使与本项目v1公式吻合，也只证明第三方实现/输入交叉核对，不独立证明原生上下限价格或当天制度正确。四字段完整独立参考目前仍缺普通制度涨跌停的独立证据。
3. 代表样本含多板块、ST及九号公司，但20个normal状态不证明这些类别适用比例、IPO/无上下限/特殊状态已分类正确。特殊表790条不能直接映射成790个当日上市A股。
4. 0x053e报价时间只有时分秒。把服务器心跳交易日拼到单股时间是日期假设，不是单股完整源时间。原初版同日推定出现负数据年龄，原记录保留；后续修正要求心跳日期核对并标假设，仍未独立验证每股日期或主机校时。
5. 特殊限制初始100页上限失败后修正：每页实返1条，最终790条和第790索引空页，共791页。生产预算必须按真实页/协议消息数，不把一次SDK调用算一次请求。
6. 原任务保存诊断的枚举序列化错误已留痕修正；不能抹去首次失败。涨跌停全量的请求数、耗时/内存、ST/停牌语义和缓存是否新鲜均未独立验收。
