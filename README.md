# AstrBot A股选股与自选监听

轻量的 AstrBot 插件 MVP：

- 收盘后按本地规则评分并推送候选股
- 盘中轮询自选股行情，触发后推送信号
- 轮询 RSS/公告流，去重后推送市场故事
- 可选调用 OpenAI 兼容模型 API 做新闻摘要
- 不提供自动下单，默认仅研究/模拟盘

## 安装

把整个目录放入 AstrBot 插件目录，在 AstrBot WebUI 安装依赖并启用插件。需要 Python 3.11+ 和 `httpx`。

## 常用命令

```text
/选股 [数量]
/自选 添加 600000
/自选 删除 600000
/自选
/监听 开启
/监听 关闭
/监听 状态
/白名单 开启
/白名单 关闭
/白名单 列表
/白名单 状态
/行情 600000
/故事 [关键词]
```

## 配置重点

- `universe_codes`：逗号分隔的股票代码。留空时，`/选股` 扫描各会话自选股。
- `quote_interval_seconds`：自选行情轮询间隔，默认 30 秒。
- `news_rss_url`：RSS 或公告聚合地址；留空则不启用故事监听。
- `push_whitelist`：后台推送白名单，填写会话的 `unified_msg_origin`，多个值用逗号或换行分隔。留空时默认不发送后台推送；也可以在目标群聊或私聊里执行 `/白名单 开启` 动态加入。执行 `/监听 状态` 可看到当前会话标识，复制到这里即可；显式填写 `*` 才会放开所有会话。
- `daily_cache_enabled`：默认开启。每个交易日收盘后抓取一次全市场日快照，保存到插件 SQLite 数据库，收盘选股优先读取当天缓存。
- `daily_cache_keep_days`：日快照保留天数，默认 180 天。只缓存日快照，不会把盘中每次行情都写入磁盘。
- `llm_enabled`、`llm_base_url`、`llm_api_key`、`llm_model`：可选模型 API。
- `paper_trading_only`：保持为 `true`。本项目没有下单接口。

全市场快照使用东方财富公开行情接口，失败时会自动退回原来的 `universe_codes`/自选股扫描；盘中监听仍只请求自选股，不会每 30 秒抓取全市场。

行情默认使用新浪批量行情接口，仅适合原型和个人研究。生产使用前请替换为稳定、合规且有授权的行情/公告数据源，并核对涨跌停、停牌、T+1、手续费和滑点。

## 树莓派建议

树莓派 4B 8G 先监听 50～100 只自选股。技术指标在本地计算，模型只处理触发的新闻或候选摘要，不要把全市场每条行情都发送给模型 API。TF 卡可用于试运行，长期运行建议 USB 3.0 SSD，并限制日志和数据库写入。

## 推送白名单

白名单同时支持群聊和私聊。只有白名单内、且已执行 `/监听 开启` 的会话，才能收到收盘选股、盘中信号和市场故事等自动推送。手动执行 `/选股`、`/行情`、`/故事` 的回复不受白名单限制，方便完成配置。
