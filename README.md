# AstrBot A股选股与自选监听

轻量的 AstrBot 插件 MVP：

- 收盘后按本地规则评分并推送候选股
- 盘中轮询自选股行情，触发后推送信号
- 轮询 RSS/公告流，去重后推送市场故事
- 可选调用 OpenAI 兼容模型 API 做新闻摘要
- 不提供自动下单，默认仅研究/模拟盘

## 安装

把整个目录放入 AstrBot 插件目录，在 AstrBot WebUI 安装依赖并启用插件。需要 Python 3.11+ 和 `httpx`。

## 常用命令

```text
/选股 [数量]
/自选 添加 600000
/自选 删除 600000
/自选
/监听 开启
/监听 关闭
/监听 状态
/行情 600000
/故事 [关键词]
```

## 配置重点

- `universe_codes`：逗号分隔的股票代码。留空时，`/选股` 扫描各会话自选股。
- `quote_interval_seconds`：自选行情轮询间隔，默认 30 秒。
- `news_rss_url`：RSS 或公告聚合地址；留空则不启用故事监听。
- `llm_enabled`、`llm_base_url`、`llm_api_key`、`llm_model`：可选模型 API。
- `paper_trading_only`：保持为 `true`。本项目没有下单接口。

行情默认使用新浪批量行情接口，仅适合原型和个人研究。生产使用前请替换为稳定、合规且有授权的行情/公告数据源，并核对涨跌停、停牌、T+1、手续费和滑点。

## 树莓派建议

树莓派 4B 8G 先监听 50～100 只自选股。技术指标在本地计算，模型只处理触发的新闻或候选摘要，不要把全市场每条行情都发送给模型 API。TF 卡可用于试运行，长期运行建议 USB 3.0 SSD，并限制日志和数据库写入。
